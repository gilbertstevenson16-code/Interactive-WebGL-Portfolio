# Interactive WebGL Portfolio

Read README.md, PROMPT.md, docs/validation.md, and THIRD_PARTY.md before editing.

This is a React/TypeScript application with a retained WebGL renderer. The application is not a Nuxt wrapper. React owns markup, routes, inputs, panels, and lifecycle subscriptions. The renderer in src/renderer/vendor is derived JavaScript, not newly authored TypeScript. Do not claim otherwise or broadly rewrite its dependencies to change copy.

Use the R2 manifest for normal development. For restricted browser previews run npm run preview:package; its output includes the same verified media locally. Present the full interactive preview using the host platform's supported preview mechanism. Never treat an unreachable remote localhost address as completion.

The supplied reference has missing vid_1.mp4 and vid_2.mp4. Their static image fallbacks are retained. Newsletter delivery has no backend. The UI reports this explicitly. Do not invent a successful subscription or replacement media.

No private credentials are required to run, verify, or package the project. Do not push, deploy, or change branding unless requested.
